# Archive Notice

This repository is an independent disaster-recovery backup of:

https://github.com/Rodert/wechat-win-versions

Original author: Rodert

The purpose of this repository is to preserve:

- the source code
- Git commit history
- branches and tags
- the automated WeChat Windows version discovery workflow

mirror the upstream repository's historical GitHub Releases or historical
release assets.
