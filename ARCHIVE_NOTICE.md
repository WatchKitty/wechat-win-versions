# Archive Notice

This repository is an independent disaster-recovery backup of:

https://github.com/Rodert/wechat-win-versions

Original author: Rodert

The purpose of this repository is to preserve:

- the source code
- Git commit history
- branches and tags
- the automated WeChat Windows version discovery workflow

To avoid duplicating a large amount of binary data, this repository does **not**
mirror the upstream repository's historical GitHub Releases or historical
release assets.

Releases in this repository are intended to contain only versions discovered
and archived by this independent repository after it was established.

The WeChat installer binaries are not modified or re-signed by this repository.

WeChat and related binaries remain the property of their respective rights
holders.

original repository author.
